**Spurtify** — это лёгкий, быстрый и современный музыкальный плеер для Windows, созданный для удобного управления, загрузки и прослушивания всей вашей музыкальной коллекции в едином минималистичном интерфейсе.

</div>

---

## ✨ Основные возможности

* **Поиск и загрузка с YouTube:** Ищите треки прямо в приложении или вставьте ссылку на видео, чтобы сохранить аудиодорожку в высоком качестве в локальную медиатеку.
* **Офлайн-медиатека:** Импортируйте целые папки с музыкой с вашего ПК и мгновенно фильтруйте треки по названию или исполнителю.
* **Управление плейлистами:** Создавайте собственные подборки, добавляйте или удаляйте треки в один клик и слушайте плейлисты без перерывов.
* **Полнофункциональный плеер:** Удобная нижняя панель управления с режимом перемешивания (*Shuffle*), повтором трека или очереди (*Repeat*), интерактивной полосой перемотки и регулятором громкости.
* **Современный тёмный интерфейс:** Контрастная тёмная тема, разработанная для комфорта глаз и высокой отзывчивости на ПК.

## 📥 Скачивание и установка (Windows)

1. Перейдите в раздел **[Releases](../../releases)** в правой части этой страницы.
2. Скачайте установщик **`Spurtify-Setup-1.0.0.exe`**.
3. Запустите скачанный файл и следуйте инструкциям мастера установки (ярлык на рабочем столе будет создан автоматически).

> **Примечание о Windows SmartScreen:** Поскольку это независимое приложение, не распространяемое через Microsoft Store, при первом запуске Windows может показать предупреждение безопасности. Нажмите **Подробнее** → **Выполнить в любом случае**, чтобы продолжить установку.

---

## 🖥️ Системные требования

* **Операционная система:** Windows 10 или Windows 11 (64-бит)
* **Подключение к интернету:** Требуется только для поиска и загрузки новых треков; воспроизведение медиатеки и плейлистов работает полностью офлайн.
