# 🎵 Spurtify

[🇺🇸 English (US)](./README.md) | [🇮🇹 Italiano](./README.it.md) | [🇷🇺 Русский](./README.ru.md) | **🇨🇳 简体中文**

**Spurtify** 是一款专为 Windows 打造的轻量、快速且现代化的桌面音乐播放器，旨在通过简洁无干扰的界面管理、下载并播放您的全部音乐库。

</div>

---

## ✨ 核心功能

* **YouTube 搜索与下载：** 直接在应用内搜索歌曲，或粘贴视频链接即可将高品质音轨保存至本地音乐库。
* **离线本地音乐库：** 一键导入电脑中的本地音乐文件夹，并支持按曲名或艺术家即时筛选。
* **播放列表管理：** 创建个性化歌单，一键添加或移除曲目，轻松管理您的播放队列。
* **全功能播放器：** 底部常驻控制栏，支持随机播放（Shuffle）、单曲/列表循环（Repeat）、交互式进度条以及独立音量调节。
* **现代深色界面：** 高对比度深色主题设计，兼顾视觉舒适度与桌面端流畅响应体验。

---

## 📥 下载与安装 (Windows)

1. 前往本页面右侧的 **[Releases](../../releases)** 区域。
2. 下载安装程序 **`Spurtify-Setup-1.1.0.exe`**。
3. 运行下载的文件并按照安装向导完成安装（程序将自动创建桌面快捷方式）。

> **Windows SmartScreen 提示：** 由于本软件为独立开发应用，未通过 Microsoft Store 分发，首次启动时 Windows 可能会弹出安全提示。请点击 **更多信息** → **仍要运行** 以继续安装。

---

## 🖥️ 系统要求

* **操作系统：** Windows 10 或 Windows 11（64 位）
* **网络连接：** 仅在搜索和下载新曲目时需要联网；本地音乐库与播放列表支持完全离线播放。
